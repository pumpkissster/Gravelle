# PDF 阅读

PDF 文件可以和图片文件夹、ZIP／CBZ 放在同一个写真库中。新建写真库或扫描写真库时，一个 PDF 文件会作为一本独立作品入库。重新扫描可以发现新增或修改的 PDF。

## 阅读

- 使用现有阅读器，支持单页、双页、连续滚动，以及从左到右、从右到左和单页上下翻页。
- 封面默认取第一页，管理员可以在作品编辑中改选其他页面或上传封面。
- 阅读位置、书签、收藏和作品资料沿用现有账户权限与保存方式；子账户只能访问管理员授权的写真库，列表展示遵循个人的显示／隐藏设置。
- 页面在服务端按需渲染成图片，浏览器不会下载整个 PDF。首次打开尚未缓存的页面可能稍慢。
- 阅读清晰度根据页面实际显示大小和屏幕像素密度选择。请求宽度分为 800、1600、2400、3200、4096 像素，并受服务端最长边及像素上限约束。书签与封面编辑使用较小预览。
- 调大窗口时，已显示的页面会等更清晰的图片加载完成后再替换；不会因清晰度切换回到页面顶部。页面预加载和浏览器解码内存仍受性能设置限制。

## 页面缓存

PDF 页面缓存位于服务端数据目录的 `pdf-pages` 子目录，由所有有权访问该作品的账号共用，按源文件版本、页码和渲染尺寸区分。修改 PDF 并重新扫描后会使用新的页面版本。

管理员可以在「设置 → 缓存管理」查看 PDF 页面缓存占用，清除缓存或设置容量上限。默认容量为 1024 MiB，容量为 0 时不保留持久页面缓存；容量不足时回收可再生页面。清除缓存不会删除原始 PDF、作品资料、书签或阅读记录，下次访问时重新生成。

Docker 部署沿用数据目录映射，不需要单独映射 PDF 缓存目录。

## 字体

PDF 已嵌入的字体随文档渲染。对于未嵌入的中文、日文、韩文字体，Docker 镜像通过 Debian 的 `fonts-noto-cjk` 提供 Noto CJK 后备字体，并安装 `fontconfig`、生成系统字体缓存。构建时检查四种语言的字体匹配以及版权文件是否存在；不需要用户下载字体或额外映射目录。字体替换可能与原文档的字形、字宽不同，重要排版建议在生成 PDF 时嵌入字体。

PDFium 的 Linux 后备字体实现读取 `/usr/share/fonts` 等系统目录。Noto CJK 及字体工具的完整授权说明保留在容器的 `/usr/share/doc/fonts-noto-cjk/copyright`、`/usr/share/doc/fontconfig/copyright` 和各依赖包的文档目录中。Noto CJK 字体采用 SIL Open Font License 1.1。

Windows 和 macOS 版使用文档内嵌字体及系统后备字体，不复制操作系统字体到发行包。

参考：[PDFium Linux 字体后备实现](https://pdfium.googlesource.com/pdfium/+/refs/heads/main/core/fxge/linux/fx_linux_impl.cpp)、[Debian Noto CJK 软件包](https://packages.debian.org/trixie/fonts-noto-cjk)、[Noto CJK 字体许可](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)。

## 限制

- 暂不支持加密 PDF，包括不需要输入密码、只限制打印或复制权限的文档。
- 单个 PDF 最多 512 MiB、10000 页；单页渲染最长边不超过 4096 像素，总像素不超过 1600 万。
- 本次提供页面图片阅读；不提供 PDF 文本选择、文内文字搜索、填写表单或下载原始 PDF。
- 页面按文档内容渲染，不显示交互表单和批注。
- PDF 页面暂不加入图片优化队列和以图搜图索引，避免扫描时自动渲染整本文件。

PDFium 渲染依赖随 Docker 和桌面发行包提供。源 PDF 保持不变。
