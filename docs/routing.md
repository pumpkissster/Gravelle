# 页面地址

开发版支持独立的页面地址，使用 `#/` 路由，适用于 Docker、Windows 启动器和直接运行 Python 服务，无需配置服务器重写规则。

| 页面 | 地址示例 |
| --- | --- |
| 主页 | `http://127.0.0.1:8080/#/home` |
| 写真库列表 | `#/libraries` |
| 单个写真库 | `#/libraries/写真库ID` |
| 最近阅读 | `#/recent` |
| 书签 | `#/bookmarks` |
| 收藏 | `#/favorites` |
| 搜索 | `#/search?q=关键词` |
| 模特列表 | `#/models` |
| 单个模特的作品 | `#/models/模特ID` |
| 设置 | `#/settings` |
| 作品详情 | `#/books/作品ID` |
| 阅读 | `#/read/作品ID?page=3` |

在页面内点击导航、写真库、模特或作品时，地址会自动更新。支持复制链接、刷新恢复、浏览器前进与后退。搜索关键词、排序和系列筛选使用 `replaceState` 更新当前地址；阅读页码也更新当前地址，不会为每个输入字符或每次翻页添加历史记录。

详情和阅读地址可带 `from` 参数，保存返回页面及其筛选条件。阅读器关闭时优先返回打开阅读器的作品详情或列表；从外部直接打开阅读链接时，关闭后显示该作品详情。

未登录时保留目标地址，完成登录后再检查当前账号的可访问内容并恢复页面。链接不携带账号、密码或令牌。已移除或无权访问的写真库、模特与作品回到相应列表，未知或格式无效的地址回到主页；服务端仍独立验证所有 API 权限。

独立页面地址从 0.8.4 起提供，服务器仍只需按原方式开放根地址，无需额外配置页面路径转发。
