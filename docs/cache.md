# 缓存管理

管理员在「设置 → 缓存管理」查看服务端封面和优化图片的实际空间占用。子账号不能读取这些管理信息或执行清理。

## 服务端资料

| 类型 | 默认目录 | 保留方式 |
| --- | --- | --- |
| 作品内页生成的小封面 | 资料目录 `covers/` | 可再生，与写真库封面共用容量上限。 |
| 手工上传的作品封面 | 资料目录 `covers/` | 作品资料，不参与自动回收或封面清理。 |
| 写真库合成封面 | 资料目录 `library-covers/` | 可再生，保留选中的作品组。 |
| 优化阅读图片 | 资料目录 `transcoded/`，或已配置的优化目录 | 持久派生资料，只由管理员明确清理。 |

可再生封面容量默认 **512 MiB**，0 表示不限。后台按文件修改时间回收较早生成的可再生封面，维护有间隔，容量上限不是瞬时磁盘硬配额。扫描统计有数量边界，达到边界时界面会提示统计不完整。不会跟随符号链接删除文件。

「清理旧副本」只删除不再被当前或待发布映射使用的优化图。「清除在用优化图」需要确认，会将符合条件的已完成作品切回原图，再删除相应派生文件；作品、阅读进度、收藏、书签和源文件保留。正在处理、等待发布或等待替换的输出受保护。有任务运行时应先暂停或等待完成，再执行清理。清除后不会自动重新优化，管理员需在图片优化页面再次选择。

图片搜索索引保存在 SQLite 中，使用「设置 → 图片搜索」自己的清理入口，不随图片缓存清理删除。浏览器图片缓存独立于服务器磁盘缓存，见[性能设置](performance.md)。

## 写真库封面

服务端从已发布且可见作品的小封面生成一张 960×480 JPEG 拼图，首页与写真库列表共用。首次缺失时后台生成，刷新不重新随机。选中作品的封面或可见状态改变后重新核对；缓存图片读取仍检查当前账号权限。

管理员打开「编辑写真库」，点击「换一组封面」，随机选择最多四本不同作品并重新合成。超过四本时避免重复同一组；只有四本时可以重新排列。此操作不扫描写真库，不修改源图片和作品封面。清除合成封面缓存会保留选图，之后访问时重新生成。
