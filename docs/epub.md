# EPUB 写真阅读

写真集 EPUB 可以与图片文件夹、ZIP／CBZ 和 PDF 放在同一个写真库中。一个 EPUB 作为一本作品入库，列表与详情显示图片页数，并使用现有图片阅读器。

## 阅读

- 支持未加密、无 DRM 的 EPUB 2 和 EPUB 3。
- 按书内阅读顺序，再按每个页面文件中图片的出现顺序读取，不按压缩包文件名排序。
- 支持 XHTML／HTML 的 `img`，以及 SVG 页面或包装中的 `image` 对图片的引用；不发送 SVG 脚本或图形代码供浏览器执行。
- 一个页面文件有多张图片时，每张图片作为一页；只有文字的目录、版权等文件不计为图片页，也不额外把封面插入正文。
- 与普通写真共用单页、双页、连续滚动、左右方向、单页上下翻页、页宽和页码跳转。
- 阅读位置、书签和收藏沿用现有账户保存方式。子账户只能访问管理员授权的写真库，个人显示／隐藏设置影响列表展示。
- 管理员可以从作品中选页或上传封面，图片型 EPUB 也可创建单本限时分享。
- 原始 EPUB 保持不变。浏览器按需读取对应图片，无须下载整本文件，不整本解压到磁盘。

## 已入库作品

升级后启动扫描或手动扫描会重新识别旧 EPUB 目录缓存，不需要删除作品再导入。作品 ID、账户和收藏保持；旧的章节与章内位置映射到对应图片页，书签与备注一并保留。重复扫描不会再次转换已升级的记录。

## 文件与部署

EPUB 使用 Python 标准库解析，并沿用现有图片阅读器，不增加阅读依赖。Docker、Windows 和 macOS 的构建配置均包含 EPUB 引擎。

部署时沿用已有写真库及数据目录映射，无须为 EPUB 增加目录映射。已部署服务需要升级到包含此功能的构建后再扫描写真库。

图片从原始文件按需读取。目录等解析资料仅保留内存缓存，最多 16 本、总计 8 MiB，不新增 EPUB 页面缓存目录或字体缓存。

## 限制

- 不支持 DRM、正文加密或需要密码的 EPUB。常见字体混淆声明可以保留，但不加载书内字体。
- 暂不支持纯文字书、DTBook、需要完整 CSS 排版或合成矢量／文字后才能形成整页的作品。
- 不执行 EPUB 内的 JavaScript，不访问远程内容，不提供音频、视频或交互表单。
- 图片支持 JPG、PNG、GIF、WebP、AVIF 和 BMP，实际显示还取决于浏览器的格式支持；不直接显示 SVG 代码。
- 单个 EPUB 最多 512 MiB、10,000 张图片、3,000 个页面文件、5,000 个目录项、20,000 个压缩条目；解压内容总计最多 1 GiB。每个页面文件最多 8 MiB、10 万个元素，单张图片最多 32 MiB、1 亿像素，目录 XML 最多 2 MiB。
- 服务端最多同时处理两个 EPUB 请求，其余排队。
- 异常压缩比例、不安全路径、重复文件名、分卷及 ZIP64 文件会被拒绝。
- EPUB 暂不加入图片优化队列或以图搜图索引。
- PDF 和普通图片作品继续使用现有阅读方式。
