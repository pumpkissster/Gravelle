# 杂志库

在侧边栏打开「杂志库」，点击「创建杂志库」，选择存放杂志的目录。杂志支持图片文件夹、ZIP／CBZ、单卷未加密 RAR 和图片型 EPUB。RAR 单页上限为 128 MiB。

## 填写简介和目录

打开一本杂志的详情页，点击「编辑资料」，在「杂志资料」中填写或粘贴文字。可以只写简介或只写目录。目录请每行写一条，页码可以和条目写在同一行。

```text
【简介】
本期以城市摄影为主题，包含作品选登和摄影师访谈。

【目录】
第 4 页　封面专题
第 16 页　摄影访谈
第 32 页　器材与技法
```

保存后，详情页会分别显示「简介」和「目录」。长简介和较长的目录可以展开。以前填写的 `【介绍】` 也会识别为简介。

「搜索 → 文字搜索」支持按杂志标题、简介或目录关键词查找。切到「杂志库」即可查看匹配的杂志。
