## 用户系统与管理员管理（0.8.4）

- 首次注册的账户为主账号（管理员）。
- 设置页仅保留“用户管理”，展示当前账号信息；管理员通过其中的“子账户管理”弹窗新增和管理子账号。
- 设置页的“子账户管理”直接显示子账户数量，包含已启用和已禁用的子账户；新增或删除后同步更新。
- 子账户新增／编辑界面统一为“基本配置”和“权限”两个页签，使用写真库卡片开关分配访问授权。
- 子账号只能由管理员创建；首次注册完成后，登录页不再提供注册入口，也不能通过注册接口自行创建子账号。
- 管理员可以修改子账号的名称（用户名）和密码。
- 管理员可以为子账号配置可访问的写真库。
- 子账号仅用于阅读，不授予编辑作品资料、管理模特、扫描写真库或移除作品等管理权限。
- 个人资料编辑分为“基本配置”和“权限”；所有账号都可以在“权限”中独立选择写真库显示或隐藏，管理员可选择全部写真库，子账号限管理员授权范围，不能借此扩大访问范围。
- 管理员可以启用、禁用或删除子账号。
- 子账号不能使用管理员的子账户管理功能。

配套迁移与设计：

- 现有单账号升级后作为管理员，保留已有写真库、作品资料和个人记录。
- 阅读进度、最近阅读、收藏、书签和阅读偏好按账户分别保存；同一账户跨设备同步。
- 写真库显示设置只影响当前账户，隐藏后可以在设置中重新显示；不改变管理员授权或其他账户的展示。
- 写真库和功能权限需要在服务端校验，覆盖列表、搜索、详情、图片及相关操作。
- 禁用、删除账户或重置密码后，使该账户原有登录会话失效。
- 删除子账号会清除其个人记录，不删除写真源文件或共享资料；主管理员不能被删除、禁用或降级。

## 模特作品列表和搜索结果的批量管理（0.8.4）

- 点击模特头像进入该模特的作品列表后，在右上角增加“管理”按钮。
- 点击“管理”后显示多选工具，可批量选择当前列表中的作品。
- 提供“修改模特”和“移除”两项操作。
- “修改模特”用所选模特替换作品原有的全部模特关联，支持多选已有模特或新建；清空关联需要单独勾选确认，保存失败保留草稿及作品选择以便重试。
- “移除”仅从 Gravelle 中移除所选作品，不删除或修改源文件，操作前进行确认。
- 搜索结果页面采用相同的管理入口、多选方式和批量操作。
- 仅管理员可使用，子账号没有这些管理入口；服务端校验权限，并以事务一次性保存全部作品，手工关联不会被重新扫描覆盖。

## Windows 启动器支持多个根文件夹（0.8.4）

- 支持添加、移除多个根文件夹，至少一个、最多 20 个；逐个检查目录可读性并防止重复。
- 保存根文件夹配置，重新启动后继续生效。
- 创建写真库时可从已配置的根目录中选择路径。
- 旧版单根目录配置自动兼容；停止服务后更改，再次启动生效。移除根目录不会删除源文件、库资料或阅读记录，相关作品在恢复目录前不可读取。

## 大尺寸图片阅读优化（待实现）

- 根据实际显示尺寸和屏幕像素密度生成并选择阅读优化图，兼顾 4K 屏幕的清晰度。

- 控制生成任务、预加载和阅读图片内存占用。

## 启动器界面与页面地址（0.8.4）

- Windows 启动器统一使用网页的粉色、浅色卡片和文字层级；可点击按钮增加独立填色、边框与悬停／按下／键盘聚焦反馈，禁用操作与光标同步。
- 启动器所有操作按钮采用随 DPI 缩放的圆角外观，保留键盘和禁用状态；阅读器顶部的阅读方式、阅读方向和图片适配改为圆角按钮及圆角选项面板，支持键盘选择与深浅背景。
- 更新按钮移到顶部版本号右侧，继续支持检查、下载和安装；正文滚动时头部与底部操作保持可见。
- 网页使用 `#/` 地址同步，覆盖写真库、搜索、模特、设置、作品详情和阅读等页面；支持刷新、前进／后退、登录后恢复及带页码的阅读链接，详见 [页面地址](routing.md)。

## 忘记密码后的本机重置（0.8.4）

- Windows 启动器增加管理员账户密码重置入口。
- Docker 提供服务器本机使用的管理员密码重置命令。
- 子账号忘记密码时，由管理员在“设置 → 用户管理 → 子账户管理”中重置。
- 保留账户、写真库、阅读进度、收藏和书签。
- 重置后使该账户原有登录会话失效。
