# Gravelle 0.9.0

本次新增 macOS 版、PDF 与 EPUB 写真阅读，以及带密码的单本限时分享，并完善图片索引、写真库封面和缓存管理。

## 更新内容

- **macOS 版**：提供 Apple 芯片与 Intel 安装包，支持多根文件夹、局域网访问、菜单栏管理和更新检查。
- **PDF 与 EPUB 写真阅读**：沿用现有翻页方式、页码、阅读进度、书签与收藏。PDF 按需生成阅读页面；图片型 EPUB 按书内图片顺序阅读，列表显示页数。
- **单本限时分享**：管理员可选择 1 天、3 天或 7 天有效期，访客凭密码阅读，无需账号。在设置中查看密码、复制链接、查看访问统计、关闭或重新分享；已关闭的记录可以删除。
- **图片索引**：新增失败列表、定位与单张／批量重试，减少重复启动图片处理进程的开销，保留任务并发、超时及内存限制。
- **写真库封面**：改为服务端生成并缓存合成封面，管理员可点击“换一组封面”随机重新组合。
- **图片优化与缓存管理**：优化详情补充未处理张数、规则版本、实际输出参数、完成时间及逐图路径；增加缓存占用查看、清理和容量设置，并控制阅读图片的内存缓存。
- **界面调整**：统一选择器、弹窗和优化列表样式；修正 Mac 启动器退出、端口输入框及应用图标显示。

## 安装与升级

- **Windows**：提供 x64 安装包和便携包。
- **macOS**：支持 macOS 15 及以上，分别下载 Apple 芯片（arm64）或 Intel（x64）版本。
- **Docker**：提供 `pumpkissster/gravelle:0.9.0`，支持 `linux/amd64` 和 `linux/arm64`。

升级前停止服务并备份完整资料目录，继续使用原有资料和作品路径；如已创建分享，一并保留资料目录中的 `share-passwords.key`。文件校验值见 `SHA256SUMS.txt`。

## 使用说明

- EPUB 面向图片写真集，不支持纯文字书或 DRM 文档；PDF 暂不支持加密文档。PDF、EPUB 暂不加入图片优化和以图搜图索引。
- 分享图片需通过会话验证，关闭或到期后拒绝新的图片请求；不能防止截图或收回已经显示的内容。
- Windows 安装程序未做代码签名，macOS 安装包未完成 Apple 公证，系统可能显示安全提示。请从本项目发行页下载。
