# Gravelle 0.9.2

本次新增可选皮肤，改进模特头像与写真库封面，并完善两套界面的显示细节。

## 更新内容

- **新增 Board 皮肤**：在“设置 → 界面设置”中切换，保留粉色主色，支持亮色与暗色主题。
- **改进模特页面**：顶部显示头像与名称，可直接编辑模特资料；头像支持从关联作品封面重新生成，优先围绕清晰人脸裁切，预览后保存。
- **改进写真库封面**：“换一组封面”优先选择上一组之外的作品，减少重复；作品较少时尽量更换组合或排列。
- **完善界面细节**：统一搜索、筛选和表单控件，优化侧栏待处理提醒、弹窗及窄屏显示。
- **同步调整经典界面**：统一用户管理按钮宽度、设置卡片与扫描提示的对齐，修正说明文字字号和服务版本排版。

## 升级说明

- 升级前停止服务，备份完整资料目录，并沿用原作品路径与挂载。
- 人脸定位在本机完成；未找到合适人脸时使用普通裁切，可预览后决定是否保存。
