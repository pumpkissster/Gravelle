本次更新包含单页与双页拖动翻页、后台任务记录、按库增量扫描，以及数据库升级备份。适用于 Windows、macOS 和 Docker。

- **拖动翻页更连贯。** 单页和双页可按住鼠标左键左右拖动。阅读器提前加载前后相邻页，双页按整组准备。拖够距离松手翻页，短拖会回弹。分享阅读也支持此操作。
- **首页更易浏览。** 写真库和杂志库卡片溢出时可用左右箭头浏览。桌面上鼠标移入该行时显示箭头。统一四个首页区块的间距和标题样式，修复首页库封面偶尔不显示的问题。消息页的未读和已读标签使用同一套样式，未读带小红点。
- **查看后台任务记录。** 管理员可查看扫描和图片索引正在处理的内容、最近失败原因及运行历史。侧边栏和任务详情共用进度。
- **按库启用增量扫描。** 管理员可在写真库或杂志库的编辑设置中开启。收到文件变更通知后，只重扫受影响的作品或目录。此功能默认关闭，定时与手动全量扫描仍可使用。网络挂载的通知支持取决于部署环境。
- **数据库升级前自动备份。** 涉及数据库结构升级时，应用先保存可独立恢复的快照。升级失败可按数据库恢复说明离线恢复。 [数据库恢复说明](https://github.com/pumpkissster/Gravelle/blob/v0.9.8/docs/database-recovery.md)
- **Windows 强制退出。** 强制结束启动器时，后台阅读服务和工作进程随之退出，释放占用的端口。

升级前请停止服务并备份完整资料目录。Docker 用户沿用现有作品路径和数据挂载，可使用 `pumpkissster/gravelle:0.9.8` 或 `latest`。
