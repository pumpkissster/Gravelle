# Gravelle 0.9.5

本次新增独立杂志库、拖拽排序和消息中心，并改善分享与全屏阅读。

- **杂志库**：支持图片文件夹、ZIP／CBZ、RAR 和图片型 EPUB。可在作品资料中填写多行介绍和目录，并通过文字搜索查找。
- **拖拽排序**：管理员可分别调整写真库和杂志库的顺序，保存后同步到库总览和侧边栏。主导航也可拖拽排序，显示与排序偏好按账号保存在当前设备。
- **消息中心**：在头像菜单查看扫描和图片优化提醒，可直接跳到对应的处理页面。标为已读后，待处理事项仍保留在消息页。
- **分享与阅读**：改善分享链接和密码的复制操作，支持一次复制两项。浏览器无法进入全屏时，可切换到沉浸阅读。
- **管理体验**：更新作品发布日期选择器及账户权限控件样式。图片优化增加可恢复的忽略列表。

RAR 阅读支持单卷、未加密的压缩包，单页上限为 128 MiB，暂不参与图片优化和以图搜图。

升级前请停止服务并备份完整资料目录，沿用原有作品路径和挂载。
