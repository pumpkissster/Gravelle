本次更新面向 Windows 和 macOS 启动器。使用 0.9.6 桌面版的用户，可以在启动器中点击「检查更新」获取新版。

- **Windows** 改用 WPF 重构启动器，改善窗口打开和滚动时的流畅度，并修正高 DPI 缩放下控件边框不均、内容裁切的问题。便携版可从根目录直接打开 `Gravelle.exe`。
- **macOS** 换用新版启动器布局，侧栏可切换「阅读器」和「高级设置」，启动、停止和打开网页固定在底部。按钮与输入框统一圆角、边框和焦点样式，侧栏图标增加留白。
- **下载** 提供 Windows x64、macOS Apple 芯片和 macOS Intel 安装包。

Docker 镜像继续使用 0.9.6。Docker 网页如果显示 0.9.7 的更新提示，可以忽略。
