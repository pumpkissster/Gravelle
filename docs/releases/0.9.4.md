# Gravelle 0.9.4

本次更新改善了长列表滚动、大图阅读和分享，并减少后台空闲时的开销。

- **长列表和连续阅读更轻量**：滚动时回收离屏卡片，保留返回位置和批量选择；连续阅读减少缓存检查的开销。
- **减少重复读取和解压**：近期读过的图片页面可以复用已校验的临时缓存；加密分享改为分块处理和发送，降低服务端的内存峰值。
- **支持更大的库内图片**：取消图片文件夹和 ZIP／CBZ 中单张原图的固定 64 MiB 文件大小限制。原图保留，以图搜图的上传上限不变。
- **自动扫描可在网页设置**：管理员可以在「设置 → 性能设置」修改扫描间隔，设为 0 可关闭定时扫描。图片优化默认按作品顺序逐本处理。
- **减少空闲开销**：图片索引和优化在空闲时降低检查频率，目录未变化时避免重复加载整库。

升级前请停止服务并备份完整资料目录，沿用原有作品路径和挂载。如果曾为 0.9.3 手动挂载修补文件，升级时请移除这些覆盖，使用新版自带文件。
