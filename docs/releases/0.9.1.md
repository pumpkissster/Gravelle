# Gravelle 0.9.1

本次新增网络设置与独立分享入口，并统一分享页面的阅读体验。

## 更新内容

- **网络设置**：新增独立设置页面，集中管理安全入口、独立分享端口和公网分享地址。
- **安全入口**：支持设置专属访问路径、随机生成入口码和复制地址；忘记入口时，可通过启动器或本地恢复命令关闭。
- **独立分享端口**：可将分享访问与登录、管理入口分开。Windows 与 macOS 可在启动器设置分享端口，Docker 通过部署时的端口映射配置。
- **公网分享地址**：支持配置分享链接使用的地址，创建和复制分享时自动使用该地址。
- **分享阅读器**：统一为普通写真阅读器的界面与操作，支持单页、双页、连续滚动、阅读方向、图片适配、全屏、进度条和快捷键。访客的阅读设置与进度保存在自己的浏览会话中。
- **阅读细节修复**：修正连续滚动跳页后的位置偏移、双页缩窗切换及图片加载失败后的重复重试，完善退出和会话失效后的图片清理。

## 升级说明

- 升级前停止服务并备份完整资料目录，保留原有作品路径和分享密码密钥。
- Docker 用户启用独立分享端口前，需要增加容器 `8081` 端口的映射。
- 安全入口是额外访问控制，不能替代账号密码与 HTTPS。
