# Gravelle 0.8.4

## 更新内容

- 新增管理员与子账号。首次注册账户和旧版已有账户作为主管理员；管理员可创建、编辑、启用、禁用或删除子账号，并为其分配写真库访问权限。子账号仅能阅读获授权内容，不能编辑作品资料、管理模特、扫描写真库或移除作品。
- 各账号的阅读进度、最近阅读、收藏、书签和个人阅读方式／方向独立保存，同一账号跨设备同步。作品资料和写真库配置继续共享。
- 所有账号可在“编辑用户信息 → 权限”中隐藏或重新显示自己的写真库；子账号只能选择管理员已授权的库，隐藏不会改变访问授权。设置页直接显示子账户总数，包含禁用账户。
- 新增主管理员忘记密码后的本机重置：Windows 启动器提供入口，Docker／源码提供交互命令。重置前备份数据库，保留原有资料并使该账户旧登录会话失效；子账号密码由管理员重置。
- Windows 启动器支持保存 1 至 20 个写真根文件夹，逐项检查目录并兼容旧单目录配置；网页目录选择器可切换根文件夹。
- 模特作品列表和搜索结果新增管理员批量管理，可替换模特关联或移除作品；移除不会删除原始文件。
- 网页各页面同步独立地址，支持复制作品与带页码的阅读链接、刷新恢复、浏览器前进／后退及登录后返回目标页面。
- 阅读器顶部的阅读方式、阅读方向和图片适配使用圆角按钮与圆角选项面板。Windows 启动器统一粉色、卡片和圆角按钮，强化悬停、焦点及禁用状态；检查更新移到顶部版本号右侧。

## 更新与备份

更新前停止服务并备份完整数据目录，更新时沿用原数据目录：

- **Windows**：停止服务并关闭旧启动器，备份完整 `%LOCALAPPDATA%\Gravelle`，下载 0.8.4 安装包覆盖安装，保留原安装位置和数据目录。便携版使用完整的新便携文件夹运行，继续保留原数据目录。无需删除账户或重新创建写真库。
- **Docker**：停止容器并备份完整数据目录，将 `.env` 中的镜像改为 `pumpkissster/gravelle:0.8.4`，保留原数据、作品挂载和运行用户，再执行 `docker compose pull` 与 `docker compose up -d`。

旧主账号与其记录会迁移到主管理员。升级后若需回退，应恢复升级前的完整数据备份，并使用对应旧版本程序；不要让两个服务同时打开同一数据目录。

## 本版范围

提供 Windows x64 安装包／便携包和 Linux amd64／arm64 Docker 镜像；Windows ARM64、macOS 安装包不在本次发行范围。安装程序尚未做代码签名，Windows 可能提示“未知发布者”。

本版按现有方式读取原图，未提供阅读优化图或对应的容量管理。
