# Gravelle 0.9.3

本次新增 HTTPS 配置，并修复宽屏布局、选择框对齐和后台封面任务的问题。

## 更新内容

- **新增 HTTPS 配置**：在“设置 → 网络设置”中开启，支持已有 PFX／P12 证书及可选密码，显示端口和监听状态。
- **适配桌面版与 Docker**：Windows／macOS 启动器支持设置 HTTPS 端口；Docker 通过部署映射端口。独立分享可共用证书，并继续与登录及管理入口隔离。
- **修复宽屏列表布局**：Board 皮肤的作品列表随窗口宽度铺开，改善 4K 屏幕上的留白。
- **修复选择框对齐**：统一经典和 Board 皮肤中单选下拉框的文字与箭头位置。
- **修复后台空转**：解决写真库封面后台任务在空闲时反复唤醒、持续占用 CPU 的问题。

## 升级说明

- 升级前停止服务，备份完整资料目录，并沿用原作品路径与挂载。
- 由外部反向代理提供 HTTPS 时，无需开启内置 HTTPS。内置 HTTPS 的证书和端口配置见[网络设置说明](../network.md)。
- 如果曾手动挂载界面修补 CSS 文件，升级后请移除该覆盖，使用新版内置样式。
