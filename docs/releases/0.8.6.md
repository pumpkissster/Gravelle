# Gravelle 0.8.6

## 更新内容

- 修复关闭作品详情弹窗后列表重新加载、回到顶部的问题。保留原列表筛选、排序、已加载作品和滚动位置；同一浏览器内刷新页面后也可恢复列表状态。
- 优化图片索引调度，避免重复扫描持续推迟逐图处理；未变化的扫描不再重复触发索引核对。
- 全库图片核对改为分批更新数据库，减少重复写入与连接开销；逐张读取图片和等待解码时复用数据库连接，保留暂停、超时与资源限制。
- 管理员图片搜索设置显示核对图片、等待后台任务、读取图片及建立特征等阶段，区分核对进度和已完成索引数量。
- 兼容部分 PNG 图片中校验异常的 `eXIf` 元数据。只在解码副本中跳过该项坏元数据，原图不变，其他图片数据校验保留。

## 升级说明

升级前停止服务并备份完整数据目录，继续使用原数据与作品路径。

- **Windows**：关闭旧启动器，备份 `%LOCALAPPDATA%\Gravelle`，使用 `Gravelle-Setup-0.8.6-x64.exe` 覆盖安装；便携版解压完整的 `Gravelle-Windows-0.8.6-x64.zip`。
- **Docker**：保留原项目、端口、运行用户与挂载，将镜像改为 `pumpkissster/gravelle:0.8.6`，拉取后重新创建容器。若单独映射 `/data/transcoded`，同时备份该目录。

已有成功索引无需清理或重建。因上述 PNG 元数据问题失败的图片，升级后可点击「重试失败图片」；当前索引仍只支持静态 JPG、PNG、WebP，AVIF、BMP 不在支持范围内。首次索引耗时仍取决于图片大小、数量、CPU 与磁盘速度。
