# Gravelle 0.9.6

本次更新让写真库和杂志库更容易查找，并增加首页与图片索引的设置。

- **区分搜索结果**：文字搜索按写真库和杂志库显示结果与命中数。以图搜图也会按库类型分组。
- **缩短侧边栏**：写真库和杂志库各显示最多 5 个快捷入口。当前打开的库始终可见，两类库的总览均支持按库名搜索。
- **自定义首页**：新增杂志库入口，可显示、隐藏及拖动排序写真库、杂志库、继续阅读和最近加入。首页设置按账号保存在当前设备。
- **选择图片索引范围**：管理员可指定参与以图搜图的库。索引运行时，侧边栏「搜索」旁会显示进度动画。
- **杂志资料填写示例**：用 `【简介】` 和 `【目录】` 分段，目录每行一条，保存后可在详情查看，也可搜索正文关键词。详见 [杂志库使用说明](https://github.com/pumpkissster/Gravelle/blob/v0.9.6/docs/magazines.md)。
- **统一界面**：界面统一使用 Board，保留亮色与暗色。更新头像菜单、图标及筛选控件，并统一库总览与搜索页的搜索框样式。

Docker 用户可在网页「设置 → 性能设置」调整自动扫描间隔。升级前请停止服务并备份完整资料目录，沿用原有媒体路径和挂载。
