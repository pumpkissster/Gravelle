# 用户与权限

本说明适用于 0.8.4 及之后版本。0.8.4 新增管理员与子账号、写真库访问授权、个人记录隔离和个人写真库显隐；更新内容见 [0.8.4 更新说明](releases/0.8.4.md)。

## 管理员与子账号

首次注册的账户为主管理员。已有安装升级后，原账户及其阅读记录、收藏、书签归主管理员，写真库、作品资料、模特和头像保留。数据库迁移前自动备份，正式升级前仍应停止服务并备份完整数据目录。

首次注册完成后关闭公开注册。设置页的“用户管理”展示当前账号信息；管理员另有“子账户管理”入口，直接显示子账户总数（包含已禁用账户），在独立弹窗中查看列表、新建子账号、修改用户名和密码、分配写真库访问权限、启用、禁用或删除子账号。主管理员不能在子账户管理中被删除、禁用或降级。

新增和编辑子账户均分为“基本配置”和“权限”两个页签。“基本配置”设置用户名、密码和启用状态；“权限”以写真库卡片开关分配访问授权，支持全选或取消全部。授权选择随“创建用户”或“保存修改”提交，关闭编辑弹窗会丢弃未保存的选择。

各账号的阅读进度、最近阅读、收藏、书签和作品阅读偏好相互独立，同一账号在不同设备上共用个人记录。作品名称、封面、日期、模特关联及写真库配置属于共享资料；管理员修改后，其他有访问权限的用户也会看到。

## 权限与写真库显示

创建子账号时默认不分配写真库，管理员按需勾选可访问的写真库。子账号可以阅读获授权作品，保存自己的进度、收藏、书签和个人阅读方向／方式。

子账号不拥有编辑作品资料、管理模特、扫描写真库或移除作品的权限。写真库创建、编辑、移除、服务器目录浏览、服务信息、版本检查和子账户管理也仅对管理员开放。

点击“设置 → 用户管理 → 编辑用户信息”打开个人资料。“基本配置”编辑头像、用户名和密码，“权限”调整写真库显示。所有账号都可以隐藏或重新显示写真库，默认全部显示，也可以全部隐藏。管理员可选择全部写真库，子账号只能选择已获授权的写真库。首页、侧栏、写真库列表、搜索、模特及个人记录列表按此设置展示。隐藏只影响当前账号的浏览展示，不改变管理员授权，不影响其他用户；已获授权作品的直接链接仍可访问。“权限”页始终列出可访问的全部写真库，方便恢复显示；管理员分配用户权限时仍可选择全部写真库。

写真库权限在服务端检查，覆盖作品列表、模特、搜索、详情、图片、封面、个人记录及修改操作。禁用、删除账号、重置密码或调整管理员分配的访问权限后，原有会话失效，需要重新登录。个人显示设置保存后立即生效，无需重新登录。

删除子账号会清除其个人记录，不删除共享写真库、作品、模特或原始图片。

## 批量管理作品

管理员在模特的作品列表或搜索结果右上角点击“管理”，选择作品后可“修改模特”或“移除”。子账号没有这些入口，服务端也拒绝相应请求。

“修改模特”替换所选作品原有的全部模特关联，可以选择已有模特或新建模特；需要清空时，取消全部模特并勾选确认。保存后不会被重新扫描或写真库默认模特覆盖。如果作品不再属于当前模特，会从该模特的列表退出。模特关联属于共享资料，有权限查看作品的其他用户也会看到变更。

“移除”操作会先确认，仅移除 Gravelle 内的作品资料及关联阅读记录，不删除或修改源文件。

## 忘记密码

子账号忘记密码时，由管理员在“设置 → 用户管理 → 子账户管理”中设置新密码；密码输入留空表示保留原密码。

主管理员忘记密码时，必须在运行服务的电脑或服务器上重置。Windows 启动器提供“重置管理员密码”入口，仅停止自己管理的阅读器进程；若数据目录被其他服务使用，应先停止对应服务。重置前自动生成数据库备份，现有资料和个人记录保留，主管理员原有登录会话失效。

源码使用交互命令，密码不会放在命令行参数中：

```sh
python password_reset.py --data /path/to/gravelle-data
```

Docker 需先停止正常服务容器，再使用同一数据卷运行一次性工具。采用本项目默认 Compose 服务名和数据路径时：

```sh
docker compose stop sumi-reader
docker compose run --rm -it --no-deps --entrypoint python sumi-reader /app/password_reset.py --data /data
docker compose up -d sumi-reader
```

Windows 安装版也支持在终端运行：

```powershell
& "$env:LOCALAPPDATA\Programs\Gravelle\GravelleServer.exe" --reset-admin-password --data "$env:LOCALAPPDATA\Gravelle\data"
```

数据目录必须已存在且包含有效管理员账户。工具不创建账户、不扫描作品，也不会重置其他用户的密码。重置前务必停止所有使用该数据目录的服务；服务运行期间会拒绝重置。
