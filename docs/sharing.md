# 单本写真分享

管理员可以从单本写真详情创建分享，在“设置 → 我的分享”二级页面查看、关闭及管理自己创建的链接。访客无需注册账户，输入访问密码后阅读这本写真。子账户不能创建或管理分享。

图片型 EPUB 与图片文件夹、ZIP／CBZ、PDF 一样按图片页分享，访客不会获得原始 EPUB 文件或书内脚本。

分享只按时间限制，有效期可选择 1 天、3 天或 7 天，从创建时开始计算。访客会话最多持续 24 小时，且不会超过分享截止时间；会话到期后可在分享仍有效时重新输入密码。管理员关闭分享会立即拒绝所有后续页面和图片请求。

访客点击“退出”后，当前阅读会话立即失效；刷新页面仍需重新输入密码，不会自动返回阅读页。退出只影响当前会话，不关闭分享，也不影响其他访客。

关闭的分享记录可以重新分享或删除。重新分享会为同一本作品生成新的链接和访问密码，旧链接不会恢复。删除只移除这条已关闭的分享记录，不删除作品、原始图片或其他分享；正在生效的分享需要先关闭后才能删除。

“我的分享”显示访问次数，创建分享的管理员也可按需查看访问密码，并通过密码框右侧的“复制”按钮复制密码。列表不会直接返回或展示密码。访问次数在访客成功验证密码并建立新的阅读会话时增加；同一有效会话内重复解锁、刷新页面、翻页或输错密码均不增加。退出阅读不会减少累计次数，退出后重新验证密码进入则新增一次。这是访问统计，不限制访问次数，也不等同于独立访客人数。重新分享的新记录从 0 次开始；旧版本未记录的访问无法回溯。

可查看的密码以加密形式保存在数据库，主密钥单独存放在服务端数据目录的 `share-passwords.key`。**备份或迁移时，需要将数据库和该密钥文件一并保留，并妥善保护密钥。** 密钥丢失或损坏后，已有分享密码无法查看，原密码仍可用于访问验证。仅保存了密码哈希的旧分享也无法还原密码，可重新分享生成新链接及密码。

分享页面只提供当前单本写真阅读，不展示写真库路径、文件名目录、用户管理、扫描等管理内容，也不授予普通账户权限。使用分享链接的设备必须能连接 Gravelle 的访问地址；本地 `127.0.0.1` 链接不能用于另一台设备。

## 图片访问与加密

图片接口需要已验证的访客会话，每次请求都检查对应分享、作品和会话是否仍然有效。仅复制图片地址到另一个浏览器，无法读取图片。图片传输使用 AES-256-GCM，密钥按访客会话随机生成，随机 96 位 IV 每个响应重新生成。协议头、分享标识和页码纳入认证，篡改数据或把另一页当作当前页会解密失败。没有明文图片回退。

阅读页在浏览器内解密后显示图片。优先使用浏览器 WebCrypto；普通局域网 HTTP 地址若没有 WebCrypto，使用服务器自带的、固定版本 `@noble/ciphers` AES-GCM 组件，不请求外部 CDN。图片及分享接口使用禁止缓存响应策略；到期或关闭后，服务器拒绝新的图片请求。

这些措施增加了复制原始图片地址和直接下载的难度，不能防止有权限的访客提取已经解密的图片，也不能防截图。关闭或到期无法收回已经显示、下载或截图的内容。

**图片层的加密不能替代 HTTPS。** 使用 HTTP 时，网络中间人仍可能看到访问密码和会话密钥，或改动网页程序。对不可信网络或公网访问，应通过受信任的 HTTPS 入口提供服务；仅在可信局域网使用 HTTP。

## 依赖

服务端使用 [pyca/cryptography](https://cryptography.io/en/latest/hazmat/primitives/aead/) 的 AESGCM；浏览器兼容组件来自 [noble-ciphers 官方项目](https://github.com/paulmillr/noble-ciphers)。源码、固定版本、完整许可证和可重现构建信息随源码分发。Intel macOS 使用最后支持该架构的官方 cryptography universal2 wheel；该组件仅使用 AES-GCM，不处理证书或 PKCS#7 数据。
