# Libre Caslon Text

The sidebar brand uses Libre Caslon Text, an open source Caslon family.
The unmodified variable font is bundled locally so the reader works offline.

- Source: https://github.com/google/fonts/tree/main/ofl/librecaslontext
- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/librecaslontext/LibreCaslonText%5Bwght%5D.ttf
- Upstream project: https://github.com/thundernixon/Libre-Caslon
- Copyright 2018 The Libre Caslon Text Project Authors.
- License: SIL Open Font License 1.1; see `OFL.txt` alongside the font.
- Downloaded: 2026-10-10.

CSS family alias: `Gravelle Caslon`. Normal style, variable weight 400–700.
The font binary and its internal family name have not been modified.
